CV

Data scientist and developer with 6+ years building data infrastructure for the Neotoma Paleoecology Database, a global paleoecology software ecosystem. I maintain the database, design API endpoints, and automate pipelines on AWS. I publish open-source packages that let scientists access and contribute data at scale, and I teach Python and machine learning, making complex data concepts approachable for non-technical audiences.

Vancouver area, BC, Canada · s.dominguez@ht-data.com

Data Scientist II

Data Scientist I
